# Sources and method

This checklist is an original practical worksheet. Technical-search guidance below is grounded in Google’s official Search Central and Search Console documentation, checked 9 October 2026. These references describe Google Search; they do not establish ranking or citation rules for every AI answer product.

## Primary references

- [Google Search technical requirements](https://developers.google.com/search/docs/essentials/technical) — crawl access, successful response, indexable content; meeting minimum requirements does not guarantee indexing.
- [Google Search developer guide](https://developers.google.com/search/docs/fundamentals/get-started-developers) — discoverable links, sitemaps, JavaScript rendering, and checking how Google sees a site.
- [SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) — content and search presentation basics.
- [Influencing title links](https://developers.google.com/search/docs/appearance/title-link) — descriptive, concise title guidance; Google can use multiple sources for a title link.
- [Robots meta tag specifications](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag) — `noindex` and related page-level instructions; crawlers must be able to fetch the directive.
- [Canonical URL guidance](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls) — redirects, canonical annotations, and sitemap inclusion as canonicalization signals.
- [Build and submit a sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap) — sitemap format and URL-selection practices.
- [General structured data guidelines](https://developers.google.com/search/docs/appearance/structured-data/sd-policies) — accuracy, content alignment, eligibility, and no guarantee of rich-result display.
- [Search Console performance reports](https://support.google.com/webmasters/answer/7576553) — clicks, impressions, CTR, average position, dimensions, and date ranges.
- [Search Console Performance data aggregation](https://support.google.com/webmasters/answer/17011364) — why property-aggregated and page-grouped results can differ.
- [Search Console query data and limitations](https://support.google.com/webmasters/answer/17011259) — some queries are omitted for privacy and report tables can be truncated.
- [Search Console URL Inspection](https://support.google.com/webmasters/answer/9012289) — inspecting what Google knows about a URL.

## Interpretation limits

- Google documentation is authoritative for Google Search behavior, not a guarantee that another search engine or generative answer system behaves the same way.
- Technical eligibility is not the same as indexing, ranking, citation, or business results.
- Search Console metrics are aggregated observations. A reported average position is not a promise that every searcher sees the page in that position.
- No vendor, tool, or checklist can guarantee that a site will be selected or cited by an answer system.
