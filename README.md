# AI Search Visibility Checklist

A practical, evidence-first worksheet for checking whether important website content is accessible, understandable, useful, and attributable when people ask search engines and AI answer tools questions about a topic.

This checklist is about improving the underlying website and measuring observable outcomes. It is not a promise of inclusion, citation, rankings, leads, or a particular AI answer. Search and answer systems change, and each may retrieve and present information differently.

## Use the checklist

1. Pick one audience, market, and set of real questions.
2. Choose a small group of important pages and complete the checks in `checklist.md`.
3. Record a dated baseline before making changes.
4. Fix access and accuracy issues first, then improve the pages that best answer the selected questions.
5. Recheck the same questions and URLs later; note what changed and what did not.

The worksheet distinguishes observable site checks from uncertain external answer-engine behavior. It does not require paid tools: use your own browser, public page source, and Search Console access where available.

## Scope and limitations

- “AI search visibility” here means whether a selected answer or search experience surfaces, cites, or accurately describes a site for a particular question. It is not a single universal metric.
- A page can be technically accessible and still not be indexed, ranked, retrieved, cited, or selected as an answer.
- No checklist, structured data, prompt, or third-party tool can guarantee those outcomes.
- Results can vary by query wording, location, language, user context, product, and time. A small manual sample is directional, not a representative measurement of all users.
- This is an educational checklist, not legal, security, accessibility, or professional SEO advice for a particular website.
